## Requirements

- Stable HTTPS paths: `/taxi/privacy/`, `/taxi/delete-account/`, `/taxi/support/`; Albanian default with `/en/` and `/de/` variants.
- Identify PREJ SH.P.K., PREJ Taxi and PREJ Driver. Use the existing public business contact.
- Account-deletion requests must be possible without logging in or installing an app. Explain that opening an email draft does not send it or delete data. Provide manual email instructions that work without JavaScript.
- Request only app, account phone number and deletion scope. Never request passwords, OTP codes, identity documents or payment-card details in this email.
- Do not claim an automated erasure workflow, approved retention period, certification, response guarantee or legal approval that has not been demonstrated.
- Privacy copy must distinguish Rider foreground location from Driver background tracking, service providers from other users, and optional permissions from core account data.
- Final privacy/retention text remains visibly a draft pending the owner's operating-policy decision and validation. No Production store submission is authorized by this implementation.
- Corporate main branch is publicly served by GitHub Pages. Review locally before publishing; preserve CNAME and all existing content.
- Native code and Samsung screenshots belong to the existing testing chat. Do not modify its files or interrupt its pilot server.

## Acceptance

Every route has complete static text, accessible language navigation, correct metadata, local assets and responsive styling. Email request instructions and links agree, contain no entered personal information in web requests, and never display a false success. Release assets use actual app screenshots, with identifying information excluded at capture. Store metadata stays within Google Play length limits and does not advertise unavailable payment methods or unsupported coverage.
