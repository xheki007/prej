Come lavoriamo

Una direzione chiara.
A ogni passo.

PREJ è un'azienda di sviluppo software del Kosovo, guidata da Xhevdet Ferizi. Uniamo architettura, design di prodotto e ingegneria per realizzare sistemi completi: l'applicazione, l'area di lavoro, le API e i dati che le supportano. Lavori direttamente con chi si assume la responsabilità della direzione tecnica.
